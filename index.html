LocalPibox.

A personal AI devstack built on Pi.dev — local, private, reproducible, forkable.

A containerized Pi coding agent paired with a local Lemonade/Qwen LLM, MCP servers, and a curated set of forked extensions. Keep the model local and private while running a reasoning-aware coding agent around it.

Quick start

curl -fsSL https://raw.githubusercontent.com/localpibox/devstack/main/scripts/install.sh | bash
lpb /path/to/project

lpb boots the container, starts the local Lemonade/Qwen backend, and opens a Pi CLI session in your project.

Architecture

Your shell → lpb → container
                    ├─ Pi CLI (custom fork: Qwen reasoning)
                    ├─ Lemonade provider (local Qwen LLM)
                    ├─ MCP servers (agent-browser, …)
                    └─ extensions: memory, subagents, footer

Fork it

Devstack is built to be forked and repointed. Edit lpb.stack.env in a devstack fork to point at your own PI_FORK, CONFIG_FORK, images, and container name. See Forking & Repointing.
